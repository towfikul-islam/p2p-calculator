# P2P Calculator

This project is a Python-based web application built using Streamlit, designed to provide a user-friendly interface for P2P cryptocurrency transactions. The application simplifies complex calculations, helping P2P communities efficiently calculate receivable and payable amounts in USDT based on buying and selling rates.

## Features

- Choose different buying and selling currencies
- Calculate receivable USDT based on buying rate
- Calculate the amount received based on selling rate
- Add multiple platforms for buying and selling to compare (upcoming)

## Requirements

To run this project, you need to have Python installed on your machine. You can install the required libraries using the following command:

```bash
pip install -r requirements.txt
```

## Running the Application

To start the Streamlit application, navigate to the project directory and run:

```bash
streamlit run src/main.py
```

This will launch the application in your default web browser.
